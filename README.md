# Hangman-Game

A Python implementation of the classic Hangman game, built with a flowchart-first approach to demonstrate algorithmic thinking and problem-solving skills.

## ✨ Features

- 🎲 Random word selection
- 🔤 Letter-by-letter guessing
- ❤️ Lives system
- 🚫 Repeated letter detection
- 🪢 ASCII Hangman visualization
- 🏆 Win/Lose conditions
